# OpenShift Airgap Architect Overlap Analysis

**Date:** 2026-05-08  
**Purpose:** Identify overlap between this repository and [openshift-airgap-architect](https://github.com/bstrauss84/openshift-airgap-architect/)

## Executive Summary

**Overall Assessment:** Minimal functional overlap. The two tools are **complementary rather than redundant**.

- **openshift-airgap-architect:** Configuration wizard for generating validated configs (imageset-config.yaml, install-config.yaml, etc.) and executing one-off oc-mirror operations
- **This repository:** Automated pipeline for recurring collection, versioned packaging, and physical media workflow

**Key Finding:** The static configuration files in this repo should be **replaced with references to airgap-architect-generated configs**.

---

## Integration Strategy

### For Demonstrations

```
Step 1: Generate Configuration
  → Use openshift-airgap-architect wizard
  → Generate imageset-config.yaml
  → Generate install-config.yaml

Step 2: Test Manual Execution
  → Use airgap-architect's built-in oc-mirror execution
  → Understand the process interactively

Step 3: Automate with Pipeline
  → Deploy this Tekton pipeline
  → Configure with airgap-architect-generated configs
  → Schedule recurring collections
```

### For Production

```
Phase 1: Configuration
  → Use airgap-architect to generate initial configs
  → Validate with test run in airgap-architect
  → Export configs to this pipeline

Phase 2: Automation
  → Deploy Tekton pipeline with generated configs
  → Set up recurring schedules
  → Configure monitoring

Phase 3: Operations
  → Use pipeline for automated collections
  → Use airgap-architect for config updates
  → Use scripts for troubleshooting
```
